# Elysium Screenshot

![Elysium Screenshot Banner](public/branding/banner.png)

Elysium Screenshot is a premium, high-performance browser extension built to streamline capturing, annotating, and exporting webpages without sacrificing privacy. Unlike typical screenshot tools, Elysium executes zero cloud processing, running completely securely within your local browser environment.

## ✨ Features

- **Full-Page Capture:** Captures entire scrolling webpages seamlessly.
- **Region & Element Select:** Instantly select exact page elements or drag to define custom areas.
- **Beautiful Visual Editor:** Annotate screenshots with a stunning glassmorphic UI.
- **Pro Tools:** Add text, arrows, shapes, highlighters, and freehand drawing.
- **Privacy Blur:** Instantly obscure sensitive info like emails or passwords with the mosaic blur tool.
- **High-Fidelity Export:** Save your work in crystal-clear PNG or PDF without any compression artifacts.
- **Zero Data Collection:** 100% locally executed using IndexedDB and in-memory canvas APIs. 

## 🛠️ Tech Stack
- [WXT](https://wxt.dev/) - Next-gen extension framework
- [React](https://react.dev/) - UI engine
- [TypeScript](https://www.typescriptlang.org/) - Type safety
- [Tailwind CSS](https://tailwindcss.com/) - Styling
- [Zustand](https://github.com/pmndrs/zustand) - State management
